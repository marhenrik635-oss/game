# 🌿 Ramuan Desa (Village Herbalist Scramble)

Game santai & adiktif bergaya *rustic claymorphism* & *cozy cottagecore*.
Tidak ada unsur neon, futuristik, maupun cyber. Murni nuansa kayu, tanah liat hangat, kebun herbal, dan pelanggan binatang rimba!

## 🎮 Cara Main
1. Pelanggan desa (Kakek Beruang, Rubah, Burung Hantu, dll) akan memesan ramuan herbal tertentu.
2. Lihat bahan yang diminta di kartu pesanan.
3. Ambil bahan yang sesuai dari keranjang kebun herbal di bawah.
4. Klik **"Racik Ramuan ✨"** untuk menyelesaikan pesanan sebelum waktu habis (60 detik).
5. Pesanan sukses menambah waktu (+4s) & skor! Racikan salah mengurangi waktu (-5s).
6. Audio sintetis ramah browser langsung via Web Audio API tanpa download aset eksternal.
